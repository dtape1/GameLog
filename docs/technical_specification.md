## 2. Мета проєкту

Розробка веб-додатку для ведення ігрового щоденника. Користувач може переглядати список ігор, додавати їх у свою бібліотеку, встановлювати статус проходження, виставляти оцінки, залишати коментарі та переглядати статистику у профілі.

---

## 3. Функціональні вимоги

### 3.1 Авторизація та реєстрація

- Реєстрація нового користувача (логін + пароль)
- Перевірка на дублікат нікнейму при реєстрації
- Авторизація через логін і пароль
- Вихід з акаунту
- Доступ до частини функціоналу лише для авторизованих користувачів

### 3.2 Список ігор (List Page)

- Відображення всіх ігор у вигляді карток з назвою, типом, картинкою та середнім рейтингом
- Пошук за назвою (регістронезалежний)
- Фільтрація за типом гри (Singleplayer / Online / Co-op)
- Сортування: за рейтингом (зростання/спадання), за назвою, за датою виходу
- Пагінація — 8 ігор на сторінці

### 3.3 Детальна сторінка гри (Detail Page)

- Відображення: назва, опис, тип, дата виходу, зображення (або плейсхолдер)
- Середній рейтинг по всіх оцінках
- Кнопка «Додати в бібліотеку» або «Змінити статус» (залежно від стану)
- Список коментарів з датою, автором, кнопками лайку/редагування/видалення
- Форма для написання нового коментаря (тільки авторизованим)

### 3.4 Бібліотека користувача

- Додавання гри в бібліотеку зі статусом:
  - `want` — Хочу пройти
  - `playing` — Проходжу
  - `completed` — Пройшов
  - `dropped` — Кинув
- Виставлення оцінки від 1 до 10 (необов'язково)
- Якщо статус `want` — оцінка не зберігається (автоматично `None`)
- Можливість оновити статус і оцінку

### 3.5 Коментарі

- Створення коментаря до гри (тільки авторизовані)
- Порожній коментар не зберігається
- Редагування власного коментаря
- Видалення власного коментаря
- Лайки — перемикання (додати/прибрати)
- Інший користувач не може редагувати/видаляти чужий коментар

### 3.6 Профіль користувача

- Відображення нікнейму та біо
- Статистика: кількість ігор у бібліотеці, середній рейтинг, кількість коментарів
- Список ігор з бібліотеки у вигляді карток зі статусом і оцінкою
- Аватар (необов'язково)

### 3.7 Головна сторінка

- Відображення топ-5 ігор за середнім рейтингом
- Кнопки переходу до каталогу та реєстрації

### 3.8 Нотатки

- Збереження особистих нотаток користувача до гри (модель `Note`)

### 3.9 Адмін-панель

- Управління моделями: `Game`, `UserGame`, `Comment`, `Profile`, `Note`
- Відображення `title` і `type` у списку ігор
- Стандартна Django admin

## 4. Нефункціональні вимоги

- Система працює у браузері (без спеціального ПЗ)
- Підтримка кількох користувачів одночасно
- Час відповіді — до 3 секунд на локальному сервері
- Збереження даних у реляційній БД (SQLite)
- Інтерфейс на українській мові
- Підтримка темної та світлої теми (перемикання зберігається в localStorage)
- Адаптивна верстка для мобільних і десктопних пристроїв

## 5. Обмеження

- Мова програмування — Python 3
- Фреймворк — Django
- База даних — SQLite (локальна)

- Без Bootstrap — власний CSS
- Реалізація тільки базового функціоналу навчального проєкту

## 7. Структура бази даних

### Моделі

#### `Profile` (зв'язок 1:1 з User)
| Поле | Тип | Опис |
|---|---|---|
| user | OneToOneField → User | Прив'язка до акаунту |
| avatar | ImageField | Аватар (необов'язково) |
| bio | TextField | Про себе |

#### `Game`
| Поле | Тип | Опис |
|---|---|---|
| title | CharField | Назва гри |
| description | TextField | Опис |
| release_date | DateField | Дата виходу |
| type | CharField (choices) | single / online / coop |
| image | ImageField | Картинка гри |

#### `UserGame` (зв'язок M:M між User і Game)
| Поле | Тип | Опис |
|---|---|---|
| user | ForeignKey → User | Користувач |
| game | ForeignKey → Game | Гра |
| status | CharField (choices) | want / playing / completed / dropped |
| rating | IntegerField (1–10) | Оцінка (необов'язково) |

#### `Comment`
| Поле | Тип | Опис |
|---|---|---|
| user | ForeignKey → User | Автор |
| game | ForeignKey → Game | Гра |
| text | TextField | Текст коментаря |
| created_at | DateTimeField | Дата створення |
| likes | ManyToManyField → User | Лайки |

#### `Note`
| Поле | Тип | Опис |
|---|---|---|
| user | ForeignKey → User | Автор |
| game | ForeignKey → Game | Гра |
| content | TextField | Текст нотатки |

### Зв'язки

- `User` → `Profile` — **1:1** (один юзер має один профіль)
- `Game` → `Comment` — **1:M** (одна гра має багато коментарів)
- `User` → `Comment` — **1:M** (один юзер має багато коментарів)
- `User` ↔ `Game` через `UserGame` — **M:M** (багато юзерів можуть мати багато ігор)
- `Comment` ↔ `User` через `likes` — **M:M** (лайки)

## 8. Маршрути (URLs)

| URL | View | Опис |
|---|---|---|
| `/` | `home` | Головна сторінка |
| `/register/` | `register_view` | Реєстрація |
| `/login/` | `login_view` | Вхід |
| `/logout/` | `logout_view` | Вихід |
| `/games/` | `game_list` | Список ігор |
| `/games/<id>/` | `game_detail` | Детальна сторінка |
| `/games/<id>/add/` | `add_to_library` | Додати в бібліотеку |
| `/profile/<username>/` | `profile_view` | Профіль юзера |
| `/comment/<id>/edit/` | `edit_comment` | Редагувати коментар |
| `/comment/<id>/delete/` | `delete_comment` | Видалити коментар |
| `/comment/<id>/like/` | `like_comment` | Лайк/анлайк |
